BETTERWAY MORTGAGE - BRAND KIT v1.0

Start with 01_Logos_SVG/logo-primary.svg for scalable use, or 02_Logos_PNG/logo-primary.png for transparent raster use.
SVG artwork uses outlined paths and requires no installed wordmark font. Outlines are traced from the selected concept and flat-colour normalised, not an original native designer master.

03_App_Icons: full-bleed square PNGs, teal and navy, 64-1024px.
04_Favicons: ICO, SVG, Apple touch icon, PNG sizes and web manifest. Install snippet provided; adjust paths to your site.
05_Brand_Guide: three-page PDF, CSS variables and JSON design tokens. Inter is a suggested companion UI font; font binaries are not included.
06_Templates: editable SVG social card and business card; HTML email signature. Bracketed fields are placeholders. Social slogans are proposed copy only. Business card is a digital template, not a press-ready file with bleed.
07_Reference: original base and selected evolution preserved unchanged.

Minimum recommended full lockup: 240px screen / 50mm print. Use symbol at small sizes. Never stretch or redraw the logo. Confirm physical print colours and final bank/product claims before publication.
